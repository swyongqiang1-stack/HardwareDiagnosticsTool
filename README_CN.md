# Windows 异常重启诊断工具

一个轻量级 Windows 诊断工具，通过分析系统 Event Log（事件日志），帮助定位电脑**随机重启 / 蓝屏 / 卡死**的可能硬件原因。

---

## 项目背景

在实际运维或日常使用中，Windows 笔记本经常会出现以下问题：

- 随机重启
- 蓝屏（BSOD）
- 突然断电
- 系统卡死无响应

这些问题通常很难定位，需要手动查看多个事件日志（Kernel、WHEA、Disk 等）。

本工具的目标是：

> 自动分析 Windows 事件日志，并给出“可能的硬件故障方向”。

---

## 功能特点

### 1. Kernel-Power 分析

分析：

- Event ID 41（异常重启）
- Bugcheck 蓝屏代码
- 非正常关机原因

---

### 2. WHEA 硬件错误分析

检测：

- CPU 硬件错误
- Cache / 核心异常
- PCIe 总线错误
- 主板硬件层错误

---

### 3. 内存诊断

识别：

- Windows Memory Diagnostic 报告
- RAM 物理损坏迹象

---

### 4. 磁盘错误检测

分析：

- NTFS 错误
- Disk 控制器错误
- 存储异常信号

---

### 5. 过热保护分析

检测：

- CPU / 主板过热自动关机
- Thermal shutdown 事件

---

## 输出内容

程序会生成一份报告，包括：

- 可能故障的硬件组件
- 各模块风险评分（CPU / RAM / Disk / GPU / Power）
- 事件日志证据
- 建议修复方案

---

## 适用场景

- 运维排障
- 企业设备问题定位
- 个人电脑频繁重启排查
- 蓝屏分析辅助工具

---

## 使用方法

以管理员身份运行：

```powershell
HardwareDiagnosticsTool.exe
```

---

## 系统要求

- Windows 10 / 11
- .NET Runtime
- 建议使用管理员权限运行（可读取完整日志）

---

## 注意事项

本工具**不直接检测硬件**，而是基于 Windows 事件日志进行“概率分析”。

因此结果属于：

> 辅助判断，而非绝对诊断
